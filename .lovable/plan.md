
# RCM Leakage Command Center — Redesign Plan

Goal: Convert the dashboard from "what happened" reporting into "why it happened + what to do now" intelligence. Scope is UI/presentation only — no changes to parsing, computation, or data model. All insights remain client-side rule-based.

---

## 1. Information Architecture (Tab Restructure)

Collapse 13 tabs into **4 focused pages**:

| New Tab | Replaces |
|---|---|
| **Command Center** (default) | Overview + Financial KPIs (top half) + Leakage hero |
| **Leakage Analysis** | Leakage + Denial + Payer Profitability |
| **Operations** | AR Management + TAT + DSO + Cash Flow |
| **Intelligence** | AI Report + MoM Trends + Corporate + Root-cause engine (new) |

Old tab components stay on disk (no deletion) but are wired behind the 4 new tabs as composed sections. Removed from `NavTabs`: `financial`, `cashflow`, `dso`, `profitability`, `tat`, `denial`, `ar`, `payer`, `mom`, `corporate`, `leakage`, `ai-report`. New nav: `command`, `leakage`, `ops`, `intel`.

---

## 2. Page 1 — Command Center (the headline page)

### A. KPI Strip — exactly 8 cards (2 rows × 4)
1. Gross Claim Value
2. Approved Amount
3. Settled Amount
4. **Leakage ₹** (highlighted, larger)
5. Approval %
6. Net Collection %
7. Settlement TAT (days)
8. Aging > 30 Days (count + ₹)

Remove from top: Avg Claim Value, Discount %, Copay %, TDS %, Policy Split, Monthly Claims Count.

### B. Claim Funnel (NEW — `ClaimFunnel.tsx`)
Horizontal stacked funnel with leakage delta at each stage:
```
Billed  →  Approved  →  Settled  →  Collected
          (Δ deduction) (Δ shortfall) (Δ uncollected)
```
Renders bars sized proportionally; right-side annotation shows ₹ leaked + % of previous stage. Built with plain divs + tailwind (no Recharts funnel needed).

### C. Alerts & Bottlenecks panel (NEW — `AlertsPanel.tsx`)
4 colored alert rows generated by rules:
- 🔴 Top insurer leakage (largest payer-deduction insurer)
- 🟠 TAT outlier (insurer with TAT > median + 50%)
- 🔴 Top denial reason (>20% share)
- 🟡 Aging risk (count of claims > 45d)

### D. Leakage Trend (line, monthly, single accent color)

Move "Hospital at a Glance" granular grid OFF this page (lives under Operations).

## 6. Visual System Tightening

- **Color palette reduced to 4 semantic roles** in `rcm-utils.ts`:
  - `critical` (deep red), `warning` (orange), `good` (green), `neutral` (grey).
  - Existing `STATUS_COLORS` retained for status-specific charts (Settled stays green) — these are status identifiers, not severity.
- KPI card: numeric size up to `text-3xl` (32px), label `text-[11px] uppercase tracking-wider`, softer shadow, more padding (`p-5`), thinner top accent only on the Leakage card.
- Section headings standardized at `text-lg font-semibold` (~18px).
- Remove all `border-t-4 border-t-rcm-600` blanket usage; reserve accent stripe for critical cards only.
- Replace remaining pies (`OverviewTab`, `LeakageTab`, `DenialTab`, `PayerTab`) with horizontal bars.
